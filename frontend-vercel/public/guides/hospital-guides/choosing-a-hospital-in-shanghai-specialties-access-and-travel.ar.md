## Key Takeaways

- ليست شنغهاي منطقة طبية واحدة متقاربة. تمتد المستشفيات الكبرى وفروعها عبر بوكسي وبودونغ ومينهانغ وتشينغبو ولينغانغ ومناطق أخرى؛ تحقق من كل عنوان في سلسلة الرعاية.
- اختر بحسب القرار السريري التالي والخدمات التي يعتمد عليها، ثم قارن الوصول الدولي والجغرافيا والتكلفة. عكس الترتيب قد ينتج خطة مريحة لكنها ضعيفة سريريًا.
- توسّع شنغهاي الخدمات الطبية الدولية بموجب سياسة للمدينة ومعيار خدمة محلي، لكن قدرات اللغة والتأمين والطوارئ وتسليم السجلات تظل مختلفة باختلاف المؤسسة والمجمع.
- يجب أن يظل التسجيل بجواز السفر والتحقق بالهاتف وهوية بطاقة المستشفى متسقة عبر الموعد والفحوص والصيدلية والإدخال.
- يرتبط مطارا بودونغ وهونغتشياو بالسكك الحديدية، لكن الانتقال العملي طبيًا يعتمد على مجمع المستشفى الفعلي والأمتعة والقدرة على التنقل وساعات الخدمة وحالة المريض.

## Content

قد يكون لمستشفى في شنغهاي مجمع مركزي قديم وفرع أحدث عبر النهر وعيادة تخصصية في حي آخر ومكتب دولي لا يغطي الطوارئ. إذا حجز المريض باسم المجموعة وحده، فقد يكون كل جزء من الرحلة «صحيحًا» بينما تفشل الخطة الكاملة.

الطريقة الأكثر أمانًا بناء أربع خرائط مترابطة: **سريرية** و**للمجمعات** و**للخدمات** و**للسفر**. أكملها بهذا الترتيب.

### الخريطة 1: حدد القرار، لا المرض وحده

قد يحتاج مريضان بالتشخيص نفسه فريقين مختلفين في شنغهاي. أحدهما يحتاج تأكيدًا باثولوجيًا؛ وآخر عملية بعد إشعاع سابق؛ وثالث تأهيلًا أو رأيًا بشأن تجربة. اكتب المخرج المطلوب أولًا:

- تشخيص مؤكد؛
- مقارنة علاجات؛
- إجراء معقد تقنيًا؛
- تدبير مضاعفة أو نكس؛
- رأي متعدد التخصصات؛
- تأهيل ووظيفة طويلة الأمد؛
- تسليم آمن للرعاية بعد علاج في مكان آخر.

ثم اسرد الخدمات الداعمة التي لا يكتمل المخرج دونها: باثولوجيا خبيرة، أو تصوير كامل، أو فحوص جزيئية، أو تخدير، أو عناية مركزة، أو بنك دم، أو خبرة عدوى، أو دعم أطفال، أو حفظ خصوبة، أو تأهيل، أو تخصص آخر.

لا تسأل فقط هل «يوجد» التخصص بالمستشفى. اسأل هل يعالج الفريق المقترح بصورة روتينية المرحلة نفسها وتاريخ العلاج السابق وملف المخاطر ذاته، وهل تتوافر الخدمات الداعمة في مجمع العلاج.

### استخدم المسميات المؤسسية مؤشرات، لا استنتاجات

قد تشير المراكز الطبية الوطنية ومراكز البحث السريري ومشروعات التخصصات الرئيسية وصفة مستشفى المستوى الثالث إلى خبرة ذات صلة. لكنها لا تحدد الطبيب المتاح أو الانتظار الحالي أو الإجراء الدقيق أو موقع الفرع أو نتيجة مريض واحد.

لكل مرشح، احصل على أربعة أسماء مكتوبة:

1. المؤسسة المرخصة؛
2. المجمع المحدد؛
3. القسم والتخصص الفرعي؛
4. الطبيب أو الفريق المسؤول.

قارن العلاج المقترح بسؤال المريض الفعلي، واسأل ما قد يجعل المستشفى يرفض أو يعيد التوجيه أو يغير الخطة بعد الوصول. خطاب ترحيب أولي ليس قبولًا سريريًا نهائيًا.

### الخريطة 2: تتبع كل تسليم بين المجمعات

ضع كل خطوة في جدول:

| الخطوة | المؤسسة/المجمع | المبنى | الخدمة المسؤولة | المخرج |
|---|---|---|---|---|
| استلام السجلات |  |  |  | قائمة الملفات المقبولة |
| الاستشارة الأولى |  |  |  | تقييم مكتوب |
| مراجعة التصوير/الباثولوجيا |  |  |  | تقرير نهائي/ملحق |
| الإجراء أو العلاج |  |  |  | سجل العملية/العلاج |
| إنقاذ المريض الداخلي |  |  |  | مسار تصعيد الرعاية |
| المتابعة |  |  |  | حزمة الخروج وتسليم الرعاية |

قد تنتقل خدمات مستشفيات شنغهاي. في مايو 2026 مثلًا، افتتح مستشفى مجمعًا جديدًا ونقل وظائف محددة للعيادات الخارجية والطوارئ والإقامة مع إبقاء رعاية داخلية أخرى بالموقع الأقدم [1]. ليس ذلك دليلًا استثنائيًا ضد المستشفى؛ بل دليل على ضرورة التحقق من العناوين والوظائف قرب موعد الزيارة.

اسأل هل تنتقل العينات أو المرضى بين المواقع، ومن يرتب النقل، وكم وقتًا قد يضيف، وأي رقم سجل طبي يتبع المريض. إذا احتُمل نقل بالإسعاف، فحدد المستشفى المستقبل قبل العلاج.

### الخريطة 3: تحقق من مستوى الخدمات منفصلًا عن المستوى السريري

تعزز سياسة شنغهاي لعام 2025 للابتكار الطبي الدولي قنوات المواعيد باللغات الأجنبية واستخدام الجواز وطرق الدفع المتعددة والفوترة التأمينية المباشرة والوثائق متعددة اللغات والتنسيق السريري. وتوجه مقدمي الخدمات أيضًا للرجوع إلى معيار شنغهاي المحلي **DB31/T 1487—2024، مواصفة خدمة الطب الدولي** [2]. المعيار سارٍ وينطبق على المنظمات المقدمة للخدمات الطبية الدولية في شنغهاي [3].

تخلق التطورات توقعات مفيدة، لا وعدًا بتشغيل كل ميزة في كل مكان. اسأل المجمع المحدد:

- أي لغات متاحة للحجز والتمريض والموافقة والاتصالات العاجلة؟
- هل المترجم مدرب على التواصل الطبي، وهل يمكن حجزه ليوم الإجراء كاملًا؟
- هل الخدمة الدولية عيادة أم جناح أم مكتب تنسيق أم مسار إقامة كامل؟
- هل تشارك القسم العادي أطباءه وغرف عملياته وعنايته المركزة ومختبره؟
- هل تصدر سجلات سريرية ثنائية اللغة أم ملخصات إدارية مترجمة فقط؟
- هل توجد طوارئ في الموقع، وهل تعمل 24/7؟
- أي شركات التأمين لديها اتفاقيات فوترة مباشرة لهذه الخدمة بعينها؟
- ما الرسم الإضافي المنطبق، وأي البنود تبقى خارج الحزمة؟

تفيد بوابة شنغهاي الرسمية للخدمات الطبية الدولية في اكتشاف مقدمي الخدمة وبيانات الاتصال [4]. أعد تأكيد الساعات والعنوان والتخصص ووضع الطوارئ مباشرة؛ فالإدراج بالدليل ليس ترتيب جودة.

### اختر مسار الرعاية باختبار حدوده

اختبر سيناريو واقعيًا واحدًا: «عند الساعة 11 مساءً، يصاب المريض بحمى أو نزف أو ضيق نفس بعد الإجراء المخطط. ماذا يحدث؟»

- قد يوفر المسار العام المعتاد موارد تخصصية وإنقاذية عميقة لكن مساعدة أقل بالإنجليزية في التنقل بين الخدمات.
- قد يحسن مسار عام دولي أو للاحتياجات الخاصة اللغة والمواعيد والغرف، لكن يجب تأكيد المرافق السريرية وتغطية الطوارئ.
- قد يوفر مستشفى خاص الوصول واستمرارية الرعاية، لكن تهم حدود أعلى حدة مرضية يستطيع التعامل معها وشركاؤه للنقل.
- قد تقدم عيادة تخصصية خارجية رأيًا ممتازًا لكنها قد لا توفر علاجًا داخليًا.

اختر المسار الذي يستطيع إنجاز الأجزاء الخطرة من الحالة، لا صاحب البريد الأول الأكثر أناقة.

### أنشئ هوية جواز واحدة تستمر طوال الزيارة

يقول دليل شنغهاي الرسمي إن جواز السفر قد يلزم للتسجيل الأول، ويصف حجز المواعيد بتطبيق «سويشنبان»، بما يشمل إضافة مريض والتحقق برسالة نصية [5]. عمليًا، قد تقبل المنصات والمستشفيات أنواع وثائق أو صيغًا مختلفة.

قبل رفع السجلات، حدد الهوية المرجعية:

- اسم الجواز كما هو مطلوب تمامًا؛
- رقم الجواز وتاريخ انتهائه؛
- تاريخ الميلاد والجنس كما يسجلهما النظام؛
- رقم هاتف محمول محلي بالبر الرئيسي أو دولي يمكن الوصول إليه؛
- رقم بطاقة المستشفى الطبية بعد التسجيل الأول.

اطلب من الموظفين ربط السجل بدل إعادة إنشائه عندما لا يجد النظام المريض. قد تفصل الهويات المكررة الحساسية والباثولوجيا والتصوير والفوترة. احتفظ بلقطات شاشة لكل ملف وموعد، لكن لا ترسل صور الجواز عبر حساب شخصي غير متحقق منه.

### صمم إقامة شنغهاي بحسب نمط الرعاية

تحتاج أنماط الرعاية المختلفة جغرافيا مختلفة:

**استشارة اختصاصية واحدة.** أقم قرب العيادة المؤكدة واترك وقتًا لإعداد الهوية والفحوص غير المتوقعة. لا تعد بنتائج في اليوم نفسه إذا احتاجت الصور الأصلية أو الباثولوجيا إعادة مراجعة.

**حزمة تشخيصية.** حسّن الترتيب لفحوص الصيام والتصوير وتسليم العينات وزيارة مراجعة النتائج. اسأل هل تقع في مبنى واحد وهل تصدر التقارير بتطبيق المستشفى أم على الورق.

**إجراء أو جراحة.** اختر السكن وفق مجمع الخروج، لا عيادة الجراح الخارجية وحدها. أكد مسار العودة دون سلالم أو تنقلات مزدحمة، مع مرافق وليلة احتياطية.

**علاج لعدة أسابيع.** راعِ الغسيل والطعام وتخزين الأدوية واحتياطات العدوى والنقل الميسر واستدامة المرافق. عنوان ذو إطلالة جميلة أقل أهمية من مسار قابل للتكرار قليل العبء.

**رعاية طفل أو بالغ معتمد على غيره.** تحقق من قواعد حضور مقدم الرعاية ووثائق الموافقة وترتيبات النوم ودعم الطوارئ والعناية المركزة المناسب للعمر، ومن يقرر إذا تأخر الوالد أو الممثل القانوني.

### يتبع اختيار المطار عنوان العلاج

يخدم مطارا بودونغ الدولي وهونغتشياو الدولي شبكات وجانبين مختلفين من المدينة. يصل خط ربط المطار مبنى هونغتشياو 2 ومبنيَي بودونغ 1/2، وعدلت شنغهاي جدول تشغيله مجددًا بدءًا من أبريل 2026 [6]. يحسن ذلك الربط لكنه لا يجعل كل مستشفى مريح الوصول بالتساوي من المطارين.

قارن:

- مسار مبنى المطار إلى المجمع في وقت الوصول الفعلي؛
- مسافة المشي وتوافر المصاعد عند التبديل؛
- الكرسي المتحرك أو مساعدة شركة الطيران؛
- مناولة الأمتعة والمعدات الطبية؛
- الوقت بعد إجراءات الهجرة واستلام الأمتعة؛
- بديل النقل البري؛
- هل ينبغي للمريض الراحة قبل فحوص العيادات الخارجية.

إذا احتاج المريض أكسجينًا أو نقالة أو عزلًا أو مراقبة سريرية أو نقلًا عاجلًا، فنسّق مسبقًا بين شركة الطيران والمطار والجمارك والإسعاف والمستشفى المستقبل. تصف جمارك شنغهاي الدخول الطبي الطارئ عملية متعددة الأطراف، لا استقبالًا عاديًا بالمطار [7].

### يتطلب الطقس واتساع المدينة مسارًا ثانيًا

قد تؤثر الأمطار الغزيرة والحرارة والأعاصير المدارية والفعاليات الكبرى في الرحلات والطرق والسكك فوق الأرض. لكل زيارة أساسية، احتفظ بما يلي:

- مسار رئيسي ميسر؛
- بديل بري ورقم المستشفى؛
- وقت كافٍ للتنقل داخل المباني؛
- الأدوية والسجلات الرئيسية مع المريض، لا في الأمتعة المشحونة؛
- خطة إذا أُلغي الطبيب أو الفحص أو النقل.

لا تضع أول موعد حساس للوقت مباشرة بعد وصول رحلة طويلة. ولا تضع آخر مراجعة إلزامية مباشرة قبل مغادرة غير قابلة للتغيير.

### تستخدم الطوارئ نظام المدينة، لا برنامج الرحلة

رقم الطوارئ الطبية في شنغهاي **120**. تقول الإرشادات الرسمية للمدينة إن الخدمة متاحة بالإنجليزية وتطلب من المتصلين العنوان والحالة وبيانات الاتصال [8]. في حالة حرجة، قد يكون أقرب مستشفى مناسب أكثر أمانًا من عبور شنغهاي للوصول إلى الاختصاصي المختار.

جهّز العنوان بالصينية ومدخل المبنى والطابق ورمز الدخول. ينبغي أن ينتظر مرافق في مكان يراه طاقم الإسعاف. احتفظ بملخص ثنائي اللغة للتشخيص والحساسيات والأدوية ومضادات التخثر والغرسات والعلاج الحديث.

لا تفترض أبدًا أن مركز عيادات دولية يعمل ليلًا. أكد حدود طوارئه قبل أول يوم علاج.

### اجعل السعر والتأمين قابلين للمقارنة

اطلب وثيقتين بدل إجمالي واحد:

1. **تقدير سريري:** الاستشارة والفحوص والأدوية والأتعاب المهنية والإجراء والأجهزة والغرفة والتأهيل واحتياطي المضاعفات؛
2. **تقدير الخدمات:** التنسيق الدولي والترجمة الشفهية والتحريرية وزيادة الغرفة الخاصة وإدارة التأمين والنقل.

اسأل أي تقدير يتغير إذا انتقل المريض من الرعاية العادية إلى الدولية أو بين المجمعات. تعتمد الفوترة المباشرة على عقد وموافقة فردية. احصل على تأكيد للتشخيص المغطى والتواريخ وكيان مقدم الخدمة وفئة الغرفة ومبلغ التحمل والمشاركة بالدفع والموافقة المسبقة والأدوية أو الأجهزة المستثناة.

ينبغي أن يذهب الدفع إلى مقدم الخدمة المرخص أو كيانه المعتمد المُفصح عنه. سجّل قواعد الاسترداد لإلغاء الإدخال والعربون غير المستخدم وخطة تغيرت بعد إعادة الفحوص.

### أكمل الترابط قبل مغادرة شنغهاي

ينبغي أن تجيب حزمة المغادرة عن ثلاث مناطق زمنية: ما حدث في شنغهاي، وما يجب على المريض فعله أثناء السفر، وما يجب على طبيب الوطن فعله تاليًا.

اجمع:

- التشخيص النهائي والتشخيصات التفريقية غير المحسومة؛
- تفاصيل الإجراء/العلاج والجرعات الفعلية؛
- تقارير الباثولوجيا والتصوير والمختبر مع الملفات الأصلية؛
- الأدوية الحالية وتواريخ البدء/الإيقاف؛
- النتائج المعلقة والمراجع المسمى؛
- تعليمات الجرح والنشاط والغذاء والعدوى؛
- الأعراض التي تتطلب 120 أو طوارئ محلية أو اتصالًا روتينيًا؛
- قيود الطيران والسفر الطويل؛
- تواريخ المتابعة ومسار تواصل طبيب مع طبيب.

إذا وُعد بسجلات ثنائية اللغة ضمن الخدمة الدولية، فحدد الوثائق وموعد التسليم. «تتوفر خدمة إنجليزية» ليست دقيقة بما يكفي.

### ورقة القرار النهائي

قبل دفع العربون، ضع الخطة في صفحة واحدة:

> **الملاءمة السريرية:** فريق مسمى ونوع الحالة  
> **سلسلة المجمعات:** استشارة / فحوص / علاج / طوارئ / مراجعة  
> **مسار الوصول:** عادي / دولي / خاص، مع حدود اللغة  
> **الهوية:** صيغة الجواز ورقم البطاقة الطبية  
> **المال:** التقدير السريري وتقدير الخدمات وموافقة شركة التأمين  
> **السفر:** مركز الوصول ومسار ميسر وسكن وهامش احتياطي  
> **الخروج:** حزمة الخروج والنتائج المعلقة والتصريح بالسفر

ينبغي حسم أي خانة فارغة قد تؤخر العلاج أو تخفي تكلفة أو تفصل المريض عن الرعاية العاجلة قبل المغادرة.

**إخلاء مسؤولية طبي:** يقدم هذا الدليل معلومات تخطيط عامة ولا يرتب مستشفيات شنغهاي أو يزكيها. يجب أن يراجع فريق سريري مؤهل التاريخ الكامل للمريض قبل قرارات العلاج أو السفر. اطلب طوارئ محلية فورية للأعراض الشديدة أو المتفاقمة سريعًا بدل تأخير الرعاية للسفر.

## المستشفيات ذات الصلة

أضف مستشفى في شنغهاي فقط بعد تأكيد المجمع الحالي وخط الخدمة والفريق المسؤول والمسار السريري الكامل. لا تكرر قائمة عامة لـ«أفضل مستشفى».

## العلاجات ذات الصلة

اربط فقط علاجًا متحققًا منه في مجمع شنغهاي المحدد ومتاحًا عبر مسار الرعاية المقترح. الاهتمام المبدئي ليس إثبات أهلية.

## الأسئلة الشائعة

### هل مركز طبي دولي في شنغهاي هو نفسه مستشفى كامل؟

ليس دائمًا. قد يكون مكتب تنسيق أو عيادة خارجية أو جناحًا أو خط خدمة كاملًا. أكد أين تُقدم فعليًا خدمات التشخيص والإجراءات والعناية المركزة والطوارئ الليلية.

### هل أستطيع استخدام الجواز للحجز عبر سويشنبان؟

يصف دليل شنغهاي الرسمي التسجيل بالجواز وخطوات المواعيد عبر سويشنبان، لكن قد تختلف الوثائق المدعومة والتحقق بالهاتف. أكد مسار المستشفى المحدد وتجنب إنشاء هويات مريض مكررة.

### هل أقيم قرب مطار بودونغ أم هونغتشياو؟

عادة ينبغي أن يحدد مجمع العلاج واحتياجات التعافي السكن. يهم قرب المطار أساسًا عند الوصول والمغادرة؛ وعادة تخلق رحلات المستشفى المتكررة العبء الأكبر.

### هل تضمن سياسة شنغهاي الطبية الدولية سجلات ثنائية اللغة وفوترة مباشرة؟

لا. تعزز السياسة السجلات متعددة اللغات وخيارات الدفع والفوترة المباشرة، بينما يبقى التنفيذ خاصًا بالمؤسسة والعقد. احصل على تأكيد مكتوب للوثائق المحددة وترتيب التأمين.

### ماذا لو كانت المواعيد المختلفة في مجمعات مختلفة؟

اسأل هل يستطيع المستشفى تجميعها. إن لم يستطع، فارسم التنقل من باب إلى باب، واترك وقتًا للتنقل داخل المباني، وأكد ربط السجلات وملفات الدفع، وحدد موقع الطوارئ لكل يوم علاج.
