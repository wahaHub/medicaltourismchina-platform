## Key Takeaways

- «يمكننا المساعدة» ليست قبولًا سريريًا. اسأل عن القسم الذي سيُدخل المريض والطبيب المسؤول وسبب الدخول والمخاطر غير المحسومة وما يجب حدوثه قبل العلاج.
- القبول السريري ليس سريرًا. أكد المستشفى القانوني والموقع الدقيق والجناح وفئة الغرفة والتاريخ المستهدف وقاعدة تحرير السرير ومسار الوصول خارج ساعات العمل.
- ابنِ هوية واحدة من جواز السفر. طابق الاسم وتاريخ الميلاد والجنس ورقم الجواز في الدعوة وسجل المستشفى وسوار المعصم والعينات والتأمين والفاتورة النهائية.
- الدفعة المقدمة وضمان شركة التأمين والمسؤولية النهائية أمور مختلفة. احصل على خريطة مكتوبة للدافعين والاستثناءات والحد والشروط المسبقة للموافقة والقاعدة إذا تغيرت الخطة.
- ابدأ الخروج عند الدخول: حدد من يستطيع نسخ السجلات وأي ملفات أصلية وفواتير تلزم ومن يترجمها وأي طبيب في الوطن يتسلم المسؤولية.

## Content

يتعثر الدخول الدولي في فجوات عادية. يقول الاختصاصي نعم، لكن السرير في موقع آخر. تصدر شركة التأمين ضمانًا، لكن الغرسة مستثناة. يصل المريض باسم جواز لا يطابق سجلًا قديمًا في المستشفى. رتّب «القسم الدولي» غرفة، لكن لم يقبل أي فريق سريري الحالة.

قبل رحلة غير طارئة، احصل على أربعة تأكيدات في ملف واحد: **سريري، وسرير/موقع، وهوية، ودفع.** لا يغني أي منها عن الآخر.

### لا تنتظر الطوارئ حزمة الدخول

تتطلب الأعراض الشديدة أو السريعة التفاقم أو العلامات الحيوية غير المستقرة أو النزف الكبير أو العجز العصبي الجديد أو ضيق النفس الشديد أو ألم الصدر أو انخفاض الوعي أو أي طارئ محتمل آخر رعاية محلية فورية. في الصين، اتصل بـ**120** أو اذهب إلى قسم الطوارئ. تتطلب الأنظمة الأساسية الوطنية إعطاء الأولوية لإنقاذ المرضى العاجلين والحرجين وتقديم المساعدة اللازمة للنقل عندما تكون الحالة خارج نطاق المؤسسة [1].

لا ترسل مريضًا تتدهور حالته إلى بهو الخدمات الدولية بخطاب دخول مخطط. اسأل المستشفى مسبقًا أي مدخل طوارئ ورقم هاتف وموقع ينبغي استخدامه إذا تغيرت الحالة أثناء السفر.

### التأكيد 1: طبيب قبل المريض

يسمي القبول السريري المفيد:

- المستشفى القانوني والقسم السريري الدقيق؛
- الطبيب المسؤول عن الدخول أو التقييم الأول؛
- السجلات التي روجعت وتواريخها؛
- التشخيص المبدئي وسبب احتمال الحاجة إلى رعاية داخلية؛
- الفحوص أو الاستشارات اللازمة قبل القرار النهائي بشأن الإجراء؛
- الحالات الرئيسية التي قد تجعل الموقع المقترح غير مناسب؛
- ما يُتوقع خلال أول 24–48 ساعة؛
- الخدمة المسؤولة إذا أصبحت الحالة أكثر تعقيدًا.

ميّز ثلاثة ردود:

1. **إقرار إداري:** استُلمت السجلات؛
2. **رأي سريري أولي:** يرى طبيب أن الحالة قد تكون مناسبة؛
3. **قبول الدخول:** يوافق قسم على تقييم المريض أو علاجه كمريض داخلي، وفق شروط معلنة.

قبول الدخول ليس ضمانًا لعملية أو نتيجة معينة. قد يغير الفحص أو علم الأمراض أو التصوير أو تحري العدوى أو تقييم التخدير الخطة. يتطلب نظام مسؤولية الاتصال الأول في الصين طرفًا مسؤولًا واضحًا واستمرارية حتى يتولى طبيب آخر [1]؛ اسأل كيف تبدأ تلك المسؤولية لمريض دولي رتّب مسبقًا.

### التأكيد 2: السرير في المكان والوقت الصحيحين

اطلب تأكيد سرير أو تعليمات دخول تتضمن:

- الاسم الصيني القانوني للمستشفى؛
- اسم الموقع وعنوانه بالصينية؛
- المبنى والطابق والجناح ومكتب الدخول؛
- القسم والفريق المعالج؛
- التاريخ المستهدف وفترة تسجيل الدخول؛
- حالة الإقامة الداخلية أو الرعاية النهارية أو الملاحظة؛
- فئة الغرفة العادية/الخاصة/الدولية وما إذا كانت مضمونة؛
- احتياجات العزل أو الإتاحة أو الأكسجين أو مقدم الرعاية أو طب الأطفال؛
- جهة اتصال للتأخير أو الوصول المتأخر أو الوصول في عطلة نهاية الأسبوع/العطلات؛
- مدة الاحتفاظ بالسرير وما الذي يحرره.

قد تعني «سرير متاح الأسبوع القادم» توقعًا، لا حجزًا. اسأل ما إذا كان السرير مشروطًا بمراجعة عيادة في اليوم نفسه أو دفعة مقدمة أو نتيجة مخبرية أو ضمان تأمين أو خروج مريض آخر. احجز سفرًا مرنًا حتى يشرح المستشفى أي تأكيد نهائي.

تحقق من المؤسسة والطبيب عبر الاستعلامات العامة الرسمية [2]. لا يثبت شعار تعاون أو مكتب خارجي أو حزمة فندق وعيادة أن جناح الدخول يتبع المستشفى المسمى.

### التأكيد 3: هوية مريض واحدة ستستمر طوال الإقامة

استخدم صفحة البيانات الشخصية في جواز السفر هوية مرجعية ما لم يوجه المستشفى بخلاف ذلك. اطلب من المستشفى تأكيد كيفية تسجيل:

- اللقب/اسم العائلة والأسماء الشخصية؛
- المسافات والشرطات والترتيب؛
- تاريخ الميلاد وعلامة الجنس؛
- الجنسية ورقم الجواز؛
- الاسم الصيني أو النقل الصوتي إذا استُخدم؛
- أرقام السجلات الطبية القديمة أو الجوازات السابقة أو التهجئات البديلة.

لا تنشئ سجلًا جديدًا لمجرد أن اسمًا قديمًا غير ملائم. اطلب من مكتب السجلات الطبية ربط النسخ المكررة أو دمجها وفق عمليته المضبوطة. تتطلب قواعد السجلات الطبية الصينية معرّفًا فريدًا للمريض مرتبطًا بوثائق الهوية، ويدعو معيار تعريف المريض الحالي إلى طريقتين للتعريف على الأقل طوال دورة الرعاية [3][4].

عند الدخول، قارن الجواز وسوار المعصم وورقة الدخول وقائمة الأدوية/الحساسيات قبل أول عينة أو تصوير أو نقل دم أو إجراء. صحح الاختلافات في مصدرها؛ ولا تعتمد على ملاحظة مكتوبة باليد قد لا تنتقل إلى أنظمة المختبر والصيدلية والفوترة.

### ابنِ حزمة سجلات للفريق الذي سيُدخل المريض

أرسل السجلات الأصلية مع فهرس سريري موجز:

- تسلسل زمني من صفحة واحدة والسؤال السريري الحالي؛
- التشخيصات والعمليات وعلم الأمراض والمضاعفات الرئيسية؛
- صور DICOM الأصلية والتقارير؛
- النتائج المخبرية مع التاريخ والوحدات والمجال المرجعي؛
- الأدوية الحالية بالأسماء العلمية والجرعة والتوقيت؛
- الحساسيات والتفاعل الفعلي؛
- الغرسات/الأجهزة وفصيلة الدم إن كانت موثقة وتاريخ العدوى/الاستعمار الجرثومي؛
- الحالة الوظيفية والتغذية والحركة واحتياجات التواصل؛
- التوجيهات المسبقة أو وثائق الممثل القانوني حيث تنطبق؛
- الجواز ومعلومات شركة التأمين/العضو في ملف إداري آمن منفصل.

علّم كل ترجمة بأنها ترجمة واحتفظ بالمصدر. اسأل عن الفحوص التي سيقبلها المستشفى والتي يجب تكرارها وسبب ذلك. لا تكفي «أحضر كل السجلات» إذا وجب ترتيب شرائح علم الأمراض أو مبرمج جهاز أو موعد غسيل كلى أو منتج دم قبل الوصول.

### التأكيد 4: للدفع مسؤول

أنشئ خريطة للدافعين بدلًا من إجمالي واحد:

| البند | المريض | شركة التأمين/السفارة/صاحب العمل | لم يُعتمد بعد |
|---|---|---|---|
| الدفعة الأولية للدخول |  |  |  |
| ترقية الغرفة/الخدمة الدولية |  |  |  |
| التشخيص والرسوم المهنية |  |  |  |
| الإجراء والغرسة والمستهلكات |  |  |  |
| الأدوية ومنتجات الدم |  |  |  |
| العناية المركزة أو المضاعفات أو الإقامة الأطول |  |  |  |
| المترجم الشفهي والمرافق والنقل |  |  |  |

لدفع الطرف الثالث، تحقق من الدافع القانوني ورقم الضمان والعملة والحد الأقصى وتواريخ الصلاحية والمستشفى/الموقع المشمول والتشخيص/الإجراء المأذون به والاستثناءات ومبلغ التحمل/المشاركة في الدفع وعملية التمديد ومن يتلقى الفواتير. ليس ضمان الدفع بالضرورة تغطية تأمينية غير محدودة، وبطاقة التأمين ليست ضمانًا.

اسأل المستشفى أي دفعة مقدمة تظل لازمة ومتى تُطلب أموال إضافية. تتطلب قواعد إدارة أسعار المستشفيات الصينية الإفصاح عن الأسعار وإتاحة رسوم الخدمات الطبية والأدوية والمستهلكات المفصلة للمريض [5]. تميز الإيصالات الطبية الإلكترونية الوطنية الدفعات المقدمة والإضافات والاستردادات ومصادر الدفع وتدعم كشف رسوم تفصيليًا [6]. اطلب الاطلاع يوميًا بدلًا من الانتظار إلى الخروج.

### ارسم حدودًا للقسم الدولي

قد ينسق مكتب دولي المواعيد وخطابات الدعوة والمترجمين الشفهيين والدفعات المقدمة والغرف والنقل والتواصل مع شركة التأمين. وينبغي ألا يحل بصمت محل الطبيب المعالج أو الصيدلية أو مكتب السجلات الطبية أو القسم المالي أو عملية الموافقة المستنيرة.

اطلب جدول مسؤوليات:

| السؤال | المسؤول المحدد |
|---|---|
| التشخيص السريري وقرار العلاج | القسم/الطبيب المعالج |
| تغييرات السرير والوصول | مكتب الدخول/الجناح |
| الترجمة الشفهية | خدمة ترجمة شفهية مؤهلة |
| الدفعة المقدمة والتقدير والضمان | المالية/الفوترة الدولية |
| هوية الجواز والسجلات المكررة | التسجيل/السجلات الطبية |
| تحديثات شركة التأمين | مدير الحالة/جهة اتصال الفوترة |
| السجلات والصور الأصلية | قسم السجلات الطبية/التصوير |
| الخروج وتسليم الرعاية في الوطن | الفريق المعالج/مدير الحالة |

إذا أشارت كل الإجابات إلى حساب مراسلة مندوب مبيعات واحد، فالمسؤولية لم تُحدد بعد على نحو كافٍ.

### اجعل يوم الوصول خاليًا من المفاجآت

احمل معك، ولا تضع فقط في الأمتعة المشحونة، الجواز وتعليمات الدخول وجهات الاتصال المسؤولة وقائمة الأدوية والأدوية الأساسية بعبواتها الأصلية ذات الملصقات والحساسيات والملخص السريري وضمان التأمين ووسائل الدفع ومعلومات الأجهزة. أكد مساعدة المطار/السكك الحديدية والكرسي المتحرك والأكسجين أو النقل الطبي بصورة منفصلة.

قبل أخذ أدوية المنزل إلى الجناح، قدمها للعاملين لمطابقة الأدوية؛ ولا تتناولها بنفسك دون اتفاق. اسأل هل يمكن لمرافق البقاء وما الهوية المطلوبة وساعات الزيارة وقواعد مكافحة العدوى والوجبات والغسيل والإنترنت والتخزين الآمن والإتاحة.

سجّل أسماء الطبيب المعالج والممرض المسؤول ومدير الحالة. خلال اليوم الأول، طابق التشخيص والأدوية والفحوص والغذاء والنشاط ومخاطر السقوط/إصابات الضغط وخطة المترجم وموعد القرار المتوقع.

### احمِ الموافقة والتواصل

الترجمة الإدارية ليست ترجمة شفهية سريرية. رتّب ترجمة شفهية مؤهلة للتشخيص والمخاطر والبدائل والتخدير والجراحة والدم والأدوية عالية الخطورة والبحث والخروج. أتح للمريض طرح الأسئلة مباشرة واستخدم إعادة الشرح للتحقق من الفهم بدلًا من قبول نموذج موقع دليلًا على الفهم.

وثّق من يمكنه تلقي المعلومات واتخاذ القرارات إذا افتقر المريض للأهلية والوصول إلى البوابات والتحدث مع شركة التأمين وجمع السجلات. تؤكد إرشادات السجلات الإلكترونية الصينية لعام 2025 مجددًا حماية الخصوصية والوصول إلى السجلات الإلكترونية حسب الدور [7]. لا تتداول جوازًا كاملًا وملفًا طبيًا عبر محادثات جماعية غير مضبوطة عندما تتاح قناة آمنة.

### أدِر الإقامة بثلاث نقاط مراجعة قصيرة

استخدم تحديثًا يوميًا أو عند مراحل محددة:

- **سريري:** ما الذي تغير، وما القرار التالي، ومن يقرر؛
- **تشغيلي:** السرير/الجناح، توقيت الفحوص، المترجم، ما يتوقف عليه الخروج؛
- **مالي:** الرسوم حتى الآن، الاعتماد المتبقي، بند جديد مرتفع التكلفة.

قبل إجراء، أكد المريض والموضع/الجهة والإجراء والحساسيات والغرسات والدم والتصوير والموافقة. وإذا توسعت الخطة خارج التقدير المأذون به، فاسأل السبب السريري أولًا ثم حدّث الدفع؛ ولا تدع التواصل المالي يصبح التفسير الوحيد لتغير سريري.

### ابدأ ملف المغادرة في يوم الدخول

تسمح قواعد السجلات الطبية الصينية للمرضى المؤهلين أو وكلائهم بطلب نسخ من ملاحظات الدخول والأوامر ونماذج الموافقة وسجلات التخدير والعمليات وتمريض العناية الحرجة وسجلات الخروج ومواد علم الأمراض والمختبر والتصوير [3]. اسأل مكتب السجلات مبكرًا عن الطلب والهوية/التفويض ووقت الإكمال والختم والصيغة وعملية تصدير الصور والترجمة.

عند الخروج، اجمع:

- التشخيصات النهائية والمشكلات غير المحسومة؛
- سجلات الإجراء/العملية والتخدير؛
- علم الأمراض والمختبر وصور DICOM؛
- معرّفات الغرسات/الأجهزة؛
- مطابقة الأدوية بالأسماء العلمية وتواريخ الإيقاف؛
- المضاعفات وحالة العدوى والجروح والقيود وعلامات التحذير؛
- موعد المتابعة وجهة اتصال محددة ومسار الطوارئ؛
- الرسوم المفصلة وسجل الدفعات المقدمة/الاسترداد والإيصال الرسمي؛
- قرار الأهلية للسفر وإقرار الطبيب المستقبِل.

خدمة الدخول الحقيقية ليست الاستقبال من المطار أو غرفة خاصة. إنها النظام الذي ينسّق المريض الصحيح والفريق والسرير والدافع والسجل، ويحافظ على هذا التنسيق حتى يقبل طبيب آخر تسليم الرعاية.

**إخلاء مسؤولية طبي:** يقدم هذا الدليل معلومات عامة لتخطيط الدخول. ولا يؤكد القبول السريري أو التغطية التأمينية أو توافر السرير أو التمثيل القانوني أو الأهلية للسفر. يجب التحقق من ذلك مع المستشفى والطبيب والدافع المعنيين للمريض المحدد.

## المستشفيات ذات الصلة

أدرج خدمة إدخال المرضى الدوليين لمستشفى فقط بعد التحقق من المؤسسة القانونية والموقع ومسار القبول السريري وعملية الهوية وقواعد الأسرة وتغطية الترجمة الشفهية ومسؤولية الفوترة ومسار الطوارئ وتسليم السجلات.

## العلاجات ذات الصلة

اربط العلاج فقط بعد أن يؤكد الطبيب المسؤول عن الدخول المسار الخاص بالمريض؛ فخطاب الدعوة أو التقدير أو حجز السرير ليس توصية علاجية.

## الأسئلة الشائعة

### هل يضمن خطاب دعوة أو قبول سريرًا في المستشفى؟

ليس بالضرورة. اسأل هل هو إقرار إداري أو قبول سريري أولي أو تعليمات سرير نهائية، واسرد الشروط التي قد تظل تغير التاريخ أو الموقع أو الجناح.

### هل أستطيع الوصول عبر قسم الطوارئ مع دخول مخطط؟

فقط إذا وجه المستشفى بذلك تحديدًا أو أصيب المريض بحالة طارئة. المساران المخطط والطارئ مختلفان؛ وينبغي للمريض المتدهور طلب رعاية طارئة فورية بدلًا من انتظار المكتب الدولي.

### لماذا يجب أن يطابق اسم جوازي كل وثيقة مستشفى؟

يقلل اتساق الهوية السجلات المكررة والأخطاء المتعلقة بالعينات والأدوية والإجراءات والتأمين والفواتير. اطلب من المستشفى ربط السجلات القديمة بدلًا من إنشاء هوية أخرى دون تدقيق.

### هل تعني الفوترة المباشرة أنني لن أدفع شيئًا؟

لا. قد يكون للتغطية حد أو استثناءات أو مبلغ تحمل أو مشاركة في الدفع أو شروط موافقة مسبقة. احصل على خريطة مكتوبة للدافعين واسأل عن تدبير الدفعات المقدمة والخدمات غير المغطاة.

### متى ينبغي أن أطلب سجلات إقامتي الداخلية؟

اسأل عن العملية عند الدخول. لا تصبح بعض الوثائق نهائية إلا بعد الخروج، لكن التحضير المبكر يساعد في تأمين تفويض الهوية والنسخ المختومة وتصدير DICOM وبيانات الغرسات والترجمة ووثائق شركة التأمين قبل السفر.
