## Key Takeaways

- Ein Krankenhausname in Chengdu ist kein Behandlungsplan. Bestätigen Sie den namentlich genannten Arzt, die Abteilung, die rechtlich verantwortliche Einrichtung, den genauen Standort, unterstützende Dienste und das Vorgehen bei Komplikationen.
- Messen Sie drei Entfernungen: die Lücke zwischen den Unterlagen und einer brauchbaren Entscheidung; die Lücke zwischen einer Fachgebietsbezeichnung und dem vollständigen Behandlungsteam; sowie die räumliche Entfernung zwischen Standort, Ankunftsort, Unterkunft und Notaufnahme.
- Chengdu Tianfu und Chengdu Shuangliu sind unterschiedliche Flughäfen. Prüfen Sie den auf jedem Flugabschnitt angegebenen Flughafen, bevor Sie ein Hotel in Krankenhausnähe wählen oder einen Besuch am selben Tag planen.
- Ein „internationaler“ Service kann bei der Koordination helfen, doch Sprachunterstützung, Direktabrechnung, stationäre Verfügbarkeit und ärztliche Betreuung außerhalb der Geschäftszeiten benötigen jeweils eine eigene schriftliche Bestätigung.
- Chengdu kann ein Zwischenstopp auf dem Weg nach West-Sichuan oder Tibet sein. Es ersetzt weder eine ärztliche Beurteilung der Höhentauglichkeit noch einen Plan für einen allmählichen Aufstieg.

## Content

Die Auswahl in Chengdu wird leichter, wenn Patienten nicht mehr fragen: „Welches Krankenhaus ist das beste?“, sondern beginnen, **drei Entfernungen** zu messen. Die erste ist klinisch: Wie weit ist die Fallakte von einer Antwort entfernt? Die zweite ist organisatorisch: Wie weit ist eine berühmte Abteilung vom vollständigen Team entfernt, das für die Versorgung benötigt wird? Die dritte ist räumlich: Welche Wege muss der Patient zwischen Flughafen oder Bahnhof, Behandlungsstandort, Hotel, Notfallversorgung und Nachbetreuung zurücklegen?

Diese Entfernungen hängen zusammen. Ein fehlender Pathologie-Objektträger kann Tage hinzufügen; eine Abteilung, die an einem anderen Standort arbeitet, kann die Route verändern; ein langer Transfer nach einem Eingriff kann eine gewöhnliche Verkehrsverzögerung zum Sicherheitsproblem machen.

### Entfernung eins: von hochgeladenen Unterlagen zu einer Entscheidung

Erstellen Sie ein datiertes Fallverzeichnis, bevor Sie Terminmöglichkeiten vergleichen. Nehmen Sie die zu prüfende Diagnose, die Entscheidungsfrist, wesentliche Symptome, den Funktionsstatus, bisherige Behandlungen, aktuelle Medikamente und Nahrungsergänzungsmittel, Allergien, aktuelle Laborergebnisse, originale Bilddateien und gegebenenfalls Pathologiematerial auf. Kennzeichnen Sie Übersetzungen als Übersetzungen und bewahren Sie die Ausgangsdokumente auf.

Bitten Sie das aufnehmende Team um schriftliche Antworten:

1. Welche Dateien wurden tatsächlich geöffnet und geprüft?
2. Dient der vorgeschlagene Besuch der Diagnose, einer Zweitmeinung, der Behandlungsplanung oder der Durchführung einer Behandlung?
3. Welche Untersuchungen müssen in Chengdu wiederholt werden und warum?
4. Welcher Befund könnte Abteilung, Standort, Zeitplan oder angebotenen Plan verändern?
5. Wer ist nach der Abreise des Patienten für ausstehende Pathologie-, Bildgebungs- oder molekulare Ergebnisse verantwortlich?

Eine Anmeldebestätigung belegt, dass ein Besuch gebucht wurde. Sie belegt nicht, dass der Arzt den Fall angenommen hat, ein stationäres Bett oder Eingriffstermin verfügbar ist oder der vorläufige Plan nach einer persönlichen Untersuchung bestehen bleibt.

### Den rechtlich verantwortlichen Anbieter prüfen, bevor Sie den Ruf beurteilen

Chinas Nationale Gesundheitskommission bietet öffentliche Informationsdienste zu Einrichtungen und medizinischem Personal an [1]. Bestätigen Sie den rechtlichen Namen der medizinischen Einrichtung und die aktuellen Angaben zur ärztlichen Tätigkeit; die Kommission hat auch das nationale elektronische Veröffentlichungssystem für Arztinformationen beschrieben [2].

Prüfen Sie anschließend Details, die ein Register nicht beantworten kann: die aktuelle Rolle des Arztes in diesem Fall, Standort und Sprechstundentermin, das Team für einen Eingriff, die krankenhausspezifische Berechtigung und die Zuständigkeit nachts oder bei Komplikationen. Ein bekannter Name, akademischer Titel oder Onlineprofil belegt nicht, dass die Person jeden Teil der Versorgung persönlich erbringt.

### Entfernung zwei: von der Fachgebietsbezeichnung zur vollständigen Versorgungskette

Erstellen Sie für jeden Kandidaten eine einseitige Übersicht der Abhängigkeiten. Stellen Sie die beabsichtigte Entscheidung oder Behandlung in die Mitte und ergänzen Sie möglicherweise benötigte Dienste: Radiologie, Pathologie, Labor und Blutbank, Anästhesie, Intensivmedizin, Apotheke, infektiologische Unterstützung, Rehabilitation, Ernährung und relevante Fachrichtungen für Begleiterkrankungen.

Notieren Sie für jede Abhängigkeit das genaue Gebäude. Große Einrichtungen in Chengdu können mehrere Standorte betreiben; selbst die offizielle Navigationsseite des West China Hospital benennt seinen Hauptstandort mit einer konkreten Adresse statt allein mit dem Krankenhausnamen [3]. Gehen Sie nicht davon aus, dass eine Abteilung, ein Operationssaal, ein Notfalldienst oder ein internationaler Schalter an jedem angegliederten Standort verfügbar ist.

Verwenden Sie eine Tabelle auf Standortebene:

| Benötigte Funktion | Benanntes Team | Genauer Standort/Gebäude | Bestätigtes Datum | Falls nicht verfügbar |
|---|---|---|---|---|
| diagnostische Überprüfung |  |  |  |  |
| definitive Behandlung |  |  |  |  |
| Anästhesie/Intensivmedizin |  |  |  |  |
| Rehabilitation |  |  |  |  |
| erneute Notfallbeurteilung |  |  |  |  |
| Nachverfolgung ausstehender Ergebnisse |  |  |  |  |

Wenn zwei Zeilen unterschiedliche Adressen verwenden, fragen Sie, ob der Patient, der Arzt, die Probe oder nur Daten bewegt werden müssen. Jede Antwort wirft andere Fragen zu Einwilligung, Zeit, Kosten und Verwahrungsverantwortung auf.

### „Internationalen Service“ als Bündel einzelner Funktionen betrachten

Sichuan veröffentlichte im vergangenen Jahrzehnt einen Serviceleitfaden für ausländische Patienten und einen Standard für internationale medizinische Dienstleistungen [4]. Diese Vorgeschichte zeigt, dass die Stadt an grenzüberschreitender Versorgung gearbeitet hat, belegt jedoch nicht, dass eine bestimmte Leistung 2026 weiterhin verfügbar ist.

Bestätigen Sie für die genaue Abteilung und den Standort jeweils gesondert:

- klinische Unterlagenprüfung vor der Anreise;
- Koordination von Terminen und Aufnahme;
- Registrierung mit Reisepass und Vergabe einer einheitlichen Patientennummer;
- qualifiziertes medizinisches Dolmetschen bei Einwilligung und Entlassung;
- englische oder zweisprachige klinische Dokumente;
- Kommunikation mit ausländischen Versicherern und Direktabrechnung, sofern beworben;
- klinische Eskalationsmöglichkeit rund um die Uhr (24 Stunden), nicht lediglich eine tagsüber erreichbare Concierge-Nummer.

Fragen Sie, wer Koordinator und Dolmetscher beschäftigt, welcher rechtliche Anbieter die Rechnung ausstellt und welche Abteilung eine Komplikation behandelt. Werbesprache darf diese Verantwortlichkeiten niemals vermischen.

### Die gesamte Identitätskette prüfen, nicht nur den ersten Termin

Geben Sie dem Krankenhaus vor der Reise den Namen exakt wie im Reisepass gedruckt, Staatsangehörigkeit, Geburtsdatum, Dokumentnummer und eine erreichbare Telefonnummer. Fragen Sie, welcher offizielle Kanal einen Reisepass akzeptiert und ob eine Festland-Mobilnummer, eine lokale Zahlungsmethode oder eine persönliche Verifizierung erforderlich ist.

Die Prüfung umfasst den gesamten Ablauf: Lassen sich mit derselben Patientenidentität Anmeldung, Laborergebnisse, Bilder, Verordnungen, Rechnungen, Aufnahmeunterlagen und Entlassungsbericht abrufen? Ein durch Leerzeichen, Namensreihenfolge oder Transliteration entstandener doppelter Datensatz kann Allergien und Ergebnisse von der Krankenakte trennen. Speichern Sie Bildschirmaufnahmen und Buchungsnummern, senden Sie aber keine Passbilder über ein ungeprüftes persönliches Konto.

### Entfernung drei: vom Ankunftsort zum Behandlungsbett

„Flughafen Chengdu“ ist nicht genau genug. Der Tianfu International Airport und der Shuangliu International Airport liegen in unterschiedlichen Teilen der Metropolregion. Offizielle Verkehrsinformationen beschreiben die Metrolinie 18 und Flughafenbusverbindungen für Tianfu [5], während Sichuans Regierungsbericht 2024 die Eröffnung der Linie 19 zur Verbindung beider Flughäfen dokumentiert [6]. Verbindungen, Betriebszeiten und Umstiege können sich ändern; prüfen Sie sie deshalb kurz vor der Reise.

Verwenden Sie den auf dem Flugticket gedruckten Flughafencode, das Terminal, die Ankunftszeit sowie die Zeit für Einreise und Gepäck statt des Stadtnamens in einer Reise-App. Wechselt die Route in Chengdu den Flughafen, kalkulieren Sie Kosten und Zeit des vollständigen Transfers mit Gepäck und den Mobilitätseinschränkungen des Patienten. Planen Sie keine fachärztliche Beurteilung unmittelbar nach einer internationalen Ankunft oder einem Flughafenwechsel.

Unterscheiden Sie bei Bahnreisen Chengdu East, Chengdu South, Chengdu West und andere betriebene Bahnhöfe. Wählen Sie erst, wenn die Standortadresse feststeht. Sichuan berichtete 2025 über Hilfsmaßnahmen für ältere, kranke, behinderte und schwangere Reisende an großen Chengduer Bahnhöfen [7]; erfragen Sie aktuelle Hilfe direkt, statt anzunehmen, dass heute derselbe Service, Eingang oder dieselben Zeiten gelten.

### Einen Erholungsradius festlegen

Der kürzeste Weg vor der Behandlung ist nicht unbedingt der sicherste Weg während der Erholung. Bitten Sie den behandelnden Arzt festzulegen:

- wie viele Nächte in Standortnähe verbracht werden sollten;
- ob Metrotreppen, lange Flure oder eine Autofahrt angemessen sind;
- welches Symptom sofortige Notfallversorgung statt einer Nachricht erfordert;
- welche 24-Stunden-Notaufnahme auf die Behandlungsakte zugreifen kann;
- ob der Patient allein reisen, fliegen oder eine lange Bahnfahrt unternehmen darf;
- wer Drainagen, Nähte oder Verbände entfernt und wer ausstehende Ergebnisse prüft.

Wählen Sie eine Unterkunft innerhalb dieses medizinisch festgelegten Radius. Prüfen Sie stufenlosen Zugang, Aufzugszuverlässigkeit, Badgestaltung, Kühlmöglichkeiten bei entsprechendem Medikamentenbedarf, Ernährungseinschränkungen und eine Route, die nicht von einer einzigen App oder Begleitperson abhängt.

### Ein Tor nach Westchina nicht mit Höhentauglichkeit verwechseln

Manche Patienten planen, von Chengdu nach West-Sichuan oder Tibet weiterzureisen. Betrachten Sie dies als zweite medizinische Reise. Die CDC weist darauf hin, dass das Höhenrisiko von der Schlafhöhe und Aufstiegsgeschwindigkeit abhängt; Reisende mit Herz- oder Lungenerkrankungen und anderen relevanten Erkrankungen sollten einen mit Höhenmedizin vertrauten Arzt konsultieren [8].

Stellen Sie Chengdu selbst nicht als Höhenexposition dar und nehmen Sie nicht an, einige Krankenhaustage dort machten einen raschen weiteren Aufstieg sicher. Nennen Sie dem Arzt das genaue nächste Ziel, Schlafhöhen, Verkehrsmittel, Aufstiegsplan, Zugang zu Sauerstoff und Notfallevakuierung sowie kürzliche Eingriffe oder Medikamentenänderungen. Hat die Behandlung Mobilität, Sauerstoffversorgung, Hämoglobin, Flüssigkeitshaushalt oder klinische Stabilität vermindert, verschieben Sie die Weiterreise, bis der verantwortliche Arzt sie genehmigt.

### Klinische Kosten von Aufenthaltskosten trennen

Verlangen Sie einen schriftlichen Kostenvoranschlag, gegliedert in vier Kostenkonten:

| Kostenkonto | Zu bestätigende Posten |
|---|---|
| klinisch | Konsultationen, Untersuchungen, Pathologie, Eingriff, Medikamente, Medizinprodukte, Anästhesie, Intensivversorgung, Rehabilitation |
| Krankenhausverwaltung | Anzahlung, Zimmerkategorie, Dolmetschen, Dokumentkopien, Zahlungsgebühren, Erstattungsregel |
| Aufenthalt in Chengdu | Flughafen- oder Bahnhofstransfers, Nahverkehr, Unterkunft, Mahlzeiten, Begleitperson, zusätzliche Nächte |
| Änderungsreserve | Wiederholungsuntersuchungen, verzögerte Pathologie, geänderte Behandlung, Komplikation, Flugänderung, verlängerte Erholung |

Wird Direktabrechnung angeboten, holen Sie eine schriftliche Bestätigung ein, die Patient, Versicherer und Police, rechtlichen Anbieter, Standort, Leistungsdaten, genehmigte Behandlung, Anzahlung, Ausschlüsse und Erstattungsunterlagen nennt. Ein Logo auf einer Krankenhauswebseite ist keine Zahlungsgarantie.

### Den Notfallplan vor der Anreise erstellen

Chinas landesweite Nummer für präklinische medizinische Notfälle lautet **120** [9]. Nutzen Sie bei starken Brustschmerzen, Schlaganfallzeichen, schweren Blutungen, Bewusstlosigkeit, Atemnot, einer schweren allergischen Reaktion oder rascher Verschlechterung die örtliche Notfallversorgung, statt quer durch die Stadt zu einem Facharzt für geplante Behandlungen zu fahren.

Führen Sie eine zweisprachige Notfallkarte mit Diagnose, Allergien, Medikamenten, Gerinnungshemmern, Implantaten, kürzlichem Eingriff, Passangaben, Chengduer Adresse, Behandlungsstandort und Notfallkontakt mit sich. Nennen Sie beim Anruf Bezirk, Straße, Gebäude, Eingang, Etage, Symptome und Rückrufnummer. Klären Sie vorab, ob der gewählte Standort eine 24-Stunden-Notaufnahme hat; eine internationale Tagesklinik verfügt möglicherweise nicht darüber.

### Bei der Entlassung die Null-Entfernungs-Prüfung anwenden

Bei der Entlassung sollten sich die drei Entfernungen auf null schließen: Die zu Hause benötigten Unterlagen sind übergeben, die Verantwortung für ausstehende Ergebnisse ist benannt und der Patient weiß, wohin er sich bei einer Verschlechterung wenden muss.

Sammeln Sie abschließende Diagnose, Behandlungs- und Eingriffsberichte, gegebenenfalls Anästhesieprotokoll, Pathologie- und Laborbefunde, Originalbildgebung, Medikamentenabgleich, Implantatdetails, Einschränkungen, Warnzeichen, Hinweise zur Reisefähigkeit, Nachsorgetermine und einen Kontakt mit angegebenen Antwortzeiten. Senden Sie das endgültige Paket an den zu Hause verantwortlichen Arzt und bitten Sie ihn, den Empfang zu bestätigen. Die Krankenhauswahl in einer Stadt ist erst abgeschlossen, wenn die Übergabe nach der Abreise aus Chengdu funktioniert.

**Medizinischer Haftungsausschluss:** Dieser Leitfaden bietet allgemeine Planungsinformationen und bewertet oder empfiehlt keine Krankenhäuser in Chengdu. Ein qualifizierter Arzt, der den vollständigen Fall geprüft hat, muss die klinische Eignung, den Reisezeitpunkt und die Höhentauglichkeit bestimmen. Nutzen Sie bei schweren oder rasch zunehmenden Symptomen sofort die örtliche Notfallversorgung.

## Häufige Fragen

### Welchen Chengduer Flughafen sollte ein internationaler Patient nutzen?

Verwenden Sie Flughafen und Terminal des tatsächlichen Flugs und vergleichen Sie dann den vollständigen Weg zum bestätigten Krankenhausstandort. Tianfu und Shuangliu sind keine austauschbaren Bezeichnungen; ein Transfer zwischen ihnen benötigt einen eigenen Zeit- und Mobilitätsplan.

### Bedeutet eine internationale medizinische Abteilung eine Behandlung auf Englisch?

Nicht unbedingt. Bestätigen Sie das Dolmetschen für die konkrete Sprechstunde, Einwilligung, Visiten, Apotheke und Entlassung. Koordinationspersonal und klinische Dolmetscher können unterschiedliche Personen mit unterschiedlichen Dienstzeiten sein.

### Kann ich ein Hotel wählen, bevor das Krankenhaus den Standort bestätigt?

Das ist riskant. Bestimmen Sie zuerst die Gebäude für Beurteilung, Behandlung, Notfälle und Nachsorge; wählen Sie dann eine Unterkunft innerhalb des ärztlich genehmigten Erholungsradius.

### Ist Chengdu ein sicherer Akklimatisierungsstopp vor einer Reise nach Tibet oder West-Sichuan?

Gehen Sie nicht davon aus. Die Sicherheit hängt von der nächsten Schlafhöhe, Aufstiegsgeschwindigkeit, Erkrankungen, kürzlicher Behandlung und Notfallzugang ab. Geben Sie einem mit Höhenmedizin vertrauten Arzt den genauen Weiterreiseplan.

### Was belegt, dass ein Chengduer Facharzt den Fall angenommen hat?

Eine schriftliche klinische Antwort sollte geprüfte Dateien, zu beantwortende Frage, verbleibende Untersuchungen, verantwortliches Team, Standort, Zeitpunkt und Bedingungen nennen, die den Plan ändern könnten. Ein Buchungsbeleg allein reicht nicht aus.
